# Solmara Glass Cat Defence

One sentence a house cat says in its own defence after knocking a glass off the table, for make.fun's "Five Seconds to Explain the Glass" bounty. The entry program writes a single sentence to `/output/entry.txt` — pure Python 3.13 standard library, deterministic, no network.

The entry line:

> The glass was empty, unguarded, and smug about it, so I performed the quality inspection this household refuses to do — and it failed, loudly.

Run it with `python3 main.py` and it writes the line to `/output/entry.txt`.
